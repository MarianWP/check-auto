# Golf Check

Чек-лист огляду Volkswagen Golf V перед покупкою. PWA: відкривається в Safari, додається на Початковий екран iPhone, працює офлайн. Працює і як Telegram Mini App. Без діагностики й товщиноміра — тільки очі, руки, вуха.

Стек: Vue 3, vue-router 4, Vite, vite-plugin-pwa, Vitest. Збірка через `npm run build`, деплой на GitHub Pages через GitHub Actions (тести → збірка → публікація).

## Що всередині

- **Довідник Golf V**: 17 моторів (бензин і дизель) з кодами, роками, ГРМ, надійністю, ГБО, типовими хворобами і цінами; 5 коробок; 5 кузовів; комплектації; VIN і заводи; спільні хвороби покоління.
- **Конфігуратор**: паливо → мотор → кузов → рік → коробка. Далі картка моделі з ринковою ціною в Україні.
- **Чек-лист**: 10 етапів, понад 100 пунктів. Пункти залежать від мотора (ланцюг чи ремінь, турбіна, DSG, ГБО тощо). Кожен пункт: як перевірити, чому важливо, вага (критично / важливо / дрібниця), відповіді «Ок», «Проблема», «Не перевірено», швидкі теги і коментар.
- **Звіт**: оцінка, вердикт, повнота огляду, бюджет на усунення проблем, порівняння з ринком, список проблем з коментарями. Можна поділитись текстом.
- **Резервна копія**: експорт усіх перевірок у файл JSON (у Telegram — у буфер обміну) і відновлення зі злиттям без втрат.

Дані зберігаються тільки в браузері телефону (localStorage). Якщо запис не вдається, апка показує попередження, а не мовчить.

## Дизайн

Єдина темна тема, незалежна від системної теми і теми Telegram. Токени лежать у `src/assets/styles/tokens.css`.

| Роль | Колір |
| --- | --- |
| Фон | `#101112` |
| Картки | `#1B1D20` |
| Припідняті елементи | `#25282C` |
| Основний текст | `#F5F5F5` |
| Вторинний текст | `#B0B4BB` |
| Акцент: дія або вибір | `#FF7A1A`, текст на ньому `#101112` |
| Успішна перевірка | `#65D68A` |
| Проблема | `#FF7169` |
| Увага | `#FFD166` |

- Оранжевий означає лише дію або вибір, тому прогрес і смужка етапів світлі, а не оранжеві.
- Виняток — шкала надійності двигунів і коробок: 4–5 зелені крапки, 3 оранжеві (`--rate-mid`), 1–2 червоні; поруч завжди є текст «N з 5».
- Шрифт Manrope Variable (SIL OFL) лежить у `src/assets/fonts/`, кешується service worker і працює офлайн.
- Розміри шрифту задано через змінну `--u`: вони ростуть разом із розміром тексту користувача (на iOS — Dynamic Type), але не більше ніж у 1.35 раза.
- Відступи лише зі шкали 4, 8, 12, 16, 24, 32 px. Основні кнопки від 52 px, решта цілей від 44 × 44 px, радіуси карток 22 px, кнопок 16 px.
- Нижня навігація і панель дій стоять у потоці, а не поверх контенту, тому останній пункт не може опинитися під кнопкою.
- Смужка з 10 сегментів показує прогрес кожного етапу огляду: на картках оглядів і в чек-листі.
- Вибране позначається не лише кольором: рамкою, заповненим значком і галочкою.
- Масштабування сторінки дозволене, зум подвійним тапом вимкнено через `touch-action`.
- Аркуші (меню, діалоги) забирають фокус, тримають Tab усередині, закриваються Esc і повертають фокус на кнопку, що їх відкрила.

## Як рахується вердикт

«Перевірено» означає відповідь «ок» або «проблема». «Пропустити» повноти не додає.

1. Є хоча б один критичний дефект → **Не рекомендуємо**, скільки б пунктів не було перевірено.
2. Перевірено менше 40 % пунктів → **Недостатньо даних**.
3. Оцінка перевіреного нижча за 65 → **Не рекомендуємо**.
4. Перевірено менше 80 % або лишилися неперевірені критичні пункти → **Огляд неповний**. Звіт показує, які саме критичні пункти ще треба пройти.
5. Огляд повний: оцінка від 85 і не більше одного важливого дефекту → **Можна брати**, інакше → **Брати з торгом**.

Пороги лежать у `src/logic/report.js` (`MIN_DATA`, `FULL_COVERAGE`).

## Розробка

```
npm install      # один раз
npm run dev      # http://localhost:5173/check-auto/
npm run build    # збірка у dist/
npm run preview  # перегляд збірки: http://localhost:4173/check-auto/
npm run icons    # перегенерувати PNG-іконки і src/icons.js
npm test         # юніт-тести логіки (Vitest)
```

Тести лежать у `tests/`: розрахунок вердикту й повноти (`report.test.js`), цілісність і фільтрація чек-листа (`checklist.test.js`), сумісність конфігурацій довідника (`golf.test.js`), перевірка збережених даних і резервної копії (`storage.test.js`). Ті самі тести запускаються в GitHub Actions перед збіркою: якщо тест падає, деплою немає.

## Публікація (GitHub Pages)

Репозиторій: `github.com/MarianWP/check-auto`, гілка `main`.

1. **Settings → Pages → Build and deployment → Source**: *GitHub Actions* (не «Deploy from a branch»).
2. Кожен `git push` у `main` запускає workflow `Deploy to GitHub Pages`: `npm ci` → `npm test` → `npm run build` → публікація `dist/`.
3. Сайт: `https://marianwp.github.io/check-auto/`. Хід деплою видно у вкладці **Actions**.

## Telegram Mini App

1. У [@BotFather](https://t.me/BotFather): `/newbot` (якщо бота ще немає), потім `/newapp` → обери бота → назва, опис, картинка 640×360 → **Web App URL**: `https://marianwp.github.io/check-auto/` → коротка назва, наприклад `golf`. Готове посилання: `https://t.me/<бот>/golf`.
2. Або `/mybots` → бот → **Bot Settings → Menu Button** → той самий URL. Тоді апка відкривається кнопкою меню в чаті з ботом.
3. Усередині Telegram апка сама розгортається на весь екран, підхоплює світлу/темну тему, а «Поділитися звітом» надсилає текст у чат. Кнопка «Назад» там лише нативна від Telegram: власну кнопку в шапці апка ховає.

## Як встановити на iPhone

1. Відкрий посилання в **Safari** (не в Chrome і не в месенджері).
2. Натисни кнопку **Поділитися** (квадрат зі стрілкою вгору).
3. Обери **На Початковий екран** → **Додати**.
4. Іконка «Golf Check» з'явиться на робочому столі. Запускається як звичайна апка, без адресного рядка, працює без інтернету.

## Як оновити дані

- Ціни та хвороби моторів: `src/data/golf.js`. Середня ринкова ціна у `MARKET.avg`, діапазони по моторах у полі `price` кожного двигуна.
- Пункти чек-листа: `src/data/checklist.js`. Поле `only` обмежує пункт тегами мотора чи коробки (`belt`, `chain`, `turbo`, `dsg`, `manual`, `petrol`, `diesel`, `pd`, `dpf`, `vr6`, `twincharger`).
- Service worker оновлюється сам при кожній збірці (хеші файлів), окремо піднімати версію не треба.
- Іконки: `npm run icons` (Lucide-джерела у `tools/lucide/`).

Ціни орієнтовні, за даними auto.ria станом на вересень 2026.
